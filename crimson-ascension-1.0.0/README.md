# Crimson Ascension

《猩红飞升》是一个面向 Minecraft 1.21.1 / NeoForge 的血腥诡异修仙模组。

当前工程已经完成基础整理：示例内容已移除，注册表与客户端入口已拆分，创造模式物品栏使用独立的
`crimson_ascension` 命名空间。

## 环境

- Minecraft 1.21.1
- NeoForge 21.1.265
- Java 21

## 开发命令

```powershell
.\gradlew.bat runClient
.\gradlew.bat runServer
.\gradlew.bat build
```

数据生成输出到 `src/generated/resources/`。

纹理是确定性生成的 Minecraft 像素素材，可重新生成：

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\generate_textures.ps1
```

## 修炼数据

每名玩家拥有服务端权威的 `CultivationState`，包含：

- `bloodQi`：活血/法力，上限随境界从 `100` 提升到 `700`
- `refinedBlood`：精血，范围 `0～100,000`
- `realm`：境界，范围 `0～6`
- `corruption`：心魔，范围 `0～1,000`

状态通过 NeoForge 数据附件保存，并在死亡后复制。数据更新只发送给对应玩家，客户端可通过
`CultivationClientCache.get()` 读取同步后的状态。

### 调试命令

命令需要管理员权限，在单机中需要开启作弊：

```text
/crimson cultivation get [targets]
/crimson cultivation set <field> <value> [targets]
/crimson cultivation add <field> <value> [targets]
/crimson cultivation reset [targets]
```

可用字段：

```text
blood_qi
refined_blood
realm
corruption
```

运行 `cultivationChecks` 可以验证数值边界、溢出保护、重置和 NBT Codec 往返：

```powershell
.\gradlew.bat cultivationChecks
```

## 第一版玩法闭环

当前“猩红飞升”创造模式物品栏和生存配方中已经包含：

- 放血刀：基础攻击伤害为 7。命中生物时施加 5 秒流血，每 2 秒造成 1 点伤害；
  流血击杀仍归属于最近攻击者。使用它击杀非玩家生物时可获取活血，单次最多获取 100 点。
- 血囊：主手使用可把体内活血封入血囊；潜行使用可把封存活血引回体内。
- 血傀刷怪蛋与血煞傀王刷怪蛋：右键方块生成对应怪物；创造模式物品栏中可直接取用。
- 凝血坛：右键打开独立兑换界面，按 `10 活血 = 1 精血` 自由选择兑换数量。

突破条件：

- 每次兑换 1 精血需要 10 点活血，并增加 1 点心魔。
- 空手潜行点击凝血坛尝试突破。
- 破境只检查并消耗 `(当前境界 + 1) × 5` 点精血，不再使用境界进度。
- 破境后只扣除本次所需精血，剩余精血保留；活血消耗不会改变精血上限。

境界被动回血：

| 境界 | 每 2 秒恢复活血 | 每 1 点生命消耗 |
|---|---:|---:|
| 凡躯、引血境 | 0 | 不触发 |
| 凝血境 | 1 | 不触发 |
| 炼髓境 | 2 | 不触发 |
| 血丹境 | 3 | 8 活血 |
| 阴神境 | 4 | 10 活血 |
| 血仙 | 5 | 12 活血 |

从血丹境开始，受伤时每 2 秒最多自动恢复 1 点生命；满血或活血不足时不会扣除活血。

推荐的操作顺序：

1. 合成放血刀、血囊和凝血坛。
2. 使用放血刀击杀生物收集活血。
3. 右键点击凝血坛打开兑换界面。
4. 选择获得精血数量并执行凝炼。
5. 空手潜行点击凝血坛完成突破。

物品、方块、流血效果和模组 Logo 均已使用专属开发期像素素材。

## 血府

在游戏内按 `V` 打开“血府”，快捷键可以在原版控制设置中修改。血府包含：

- 1 个中央血种槽。
- 3 个功法印记槽。
- 3 个仪式祭品槽。
- 玩家主背包与快捷栏。

血府内容保存在玩家数据附件中，并随玩家死亡复制。当前基础版本允许任意物品放入专属槽位；
后续加入血种、功法和仪式系统时，再按物品类型限制槽位。

屏幕左上角显示三条紧凑状态条：红色生命、蓝色活血、黄色精血。
红色生命条左侧显示玩家当前境界，红、蓝条内显示当前值/上限；
黄色精血条不显示数字，长度对应本次破境所需精血。
精血和心魔的具体数值只在凝血坛界面显示。
按 `H` 打开独立的“修炼状态”界面选择道途；
管理员也可以通过以下命令打开血府：

```text
/crimson vault
```

各境界活血上限：

| 境界 | 活血上限 |
|---|---:|
| 凡躯 | 100 |
| 引血境 | 200 |
| 凝血境 | 300 |
| 炼髓境 | 400 |
| 血丹境 | 500 |
| 阴神境 | 600 |
| 血仙 | 700 |

## 怪物境界

所有敌对生物加入世界时会从 `0～6` 中随机获得一个境界，与玩家当前境界无关。
血煞傀王使用更高的 `3～6` 境界范围。
境界会附加在怪物名称后，并永久保存在实体数据中；区块重载或玩家破境不会改变它。
只有管理员使用境界指令时，已经生成怪物的境界才会被直接修改。

不同境界使用独立倍率：

| 境界 | 生命倍率 | 攻击倍率 | 速度倍率 | 额外护甲 |
|---|---:|---:|---:|---:|
| 凡躯 | 1.00 | 1.00 | 1.00 | 0 |
| 引血境 | 1.45 | 1.25 | 1.03 | 2 |
| 凝血境 | 2.00 | 1.55 | 1.06 | 4 |
| 炼髓境 | 2.65 | 1.90 | 1.09 | 6 |
| 血丹境 | 3.40 | 2.30 | 1.12 | 9 |
| 阴神境 | 4.30 | 2.75 | 1.15 | 12 |
| 血仙 | 5.40 | 3.30 | 1.18 | 16 |

倍率只作用于怪物自身基础属性，不会因为区块反复加载而重复叠加。管理员可以查询或调整
指定敌对生物的境界：

```text
/crimson monster realm get <目标>
/crimson monster realm set <0-6> <目标>
```

血煞傀王通过指令设置时，低于三阶的值会被自动提升为三阶。

## 道途与功法

达到引血境后，可在 `H` 修炼状态界面选择一条永久道途：

- 血河
- 枯骨
- 鬼胎

道途选定后不能更改，使用 `/crimson cultivation reset` 重置修炼状态后可以重新选择。

功法快捷键：

```text
R         施展初级功法
Shift+R   施展进阶功法
```

每个道途拥有两项主动功法：

| 道途 | 初级功法 | 进阶功法 |
|---|---|---|
| 血河 | 血遁：沿视线方向短距离传送 | 血爆：对周围生物造成伤害和流血 |
| 枯骨 | 骨甲：获得抗性和伤害吸收 | 唤骨傀：召唤敌对血傀 |
| 鬼胎 | 鬼影：隐身并提高速度 | 摄魂：使周围生物虚弱和减速 |

道途被动：

- 血河：使用放血刀击杀时恢复 1 点生命。
- 枯骨：受到的摔落伤害降低 50%。
- 鬼胎：每 10 秒自动降低 1 点心魔。

## 血月

每天夜晚有 25% 概率触发血月。血月期间会向玩家附近生成最多 3 只血傀。
当前血傀使用原版僵尸外观和放血刀作为开发期表现，后续会替换为专属模型与纹理。

血月和高于 300 的心魔会触发心跳与绯红孢子，高心魔还会增强屏幕边缘的血雾效果。

## 配置与验收

专用服务器首次启动后会生成 `config/crimson_ascension-common.toml`，可调整：

- 血月概率与每夜血傀上限。
- 初级、进阶功法的消耗和冷却。
- 骨纹法阵活血成本。
- 血煞傀王最大生命。
- 每个境界提供的最大生命加成。
- 功法召唤血傀的存在时间。

当前默认数值基线见 [docs/BALANCE.md](docs/BALANCE.md)，完整发布前测试步骤见
[docs/QA_CHECKLIST.md](docs/QA_CHECKLIST.md)。
