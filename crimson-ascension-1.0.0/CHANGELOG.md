# Changelog

## Unreleased

- Removed realm progress entirely; breakthroughs now depend only on refined blood.
- Reduced the cultivation HUD to compact health, blood qi, and refined-blood bars, with
  numeric values on health and blood qi and no number on refined blood.
- Added the player's current realm name beside the health bar.
- Moved all exact resource values to the Blood Condensation Altar interface.
- Added persistent random `0-6` cultivation realms to hostile monsters, with realm-based
  health, attack, speed, armor, visible realm names, and debug commands.
- Restricted the Blood Fiend to the `3-6` realm range.
- Added Blood Puppet and Blood Fiend spawn eggs with dedicated pixel textures.
- Added realm-scaled passive blood qi recovery from Blood Condensation, and
  blood-powered healing from Blood Core onward.

## 1.0.0

- Initial playable Crimson Ascension release candidate.
- Added cultivation data, realm progression, blood qi, refined blood, and corruption.
- Added Bloodletting Dagger with bleeding damage over time.
- Added reusable Blood Vial and Blood Condensation Altar.
- Added Blood Vault inventory and cultivation HUD.
- Added Blood River, Withered Bone, and Ghost Womb paths.
- Added six path techniques and three path passives.
- Added Blood Puppet encounters, Blood Moon, and the Blood Fiend boss.
- Added Bone Rune Formation support ritual.
- Added dedicated item, block, effect, and mod logo textures.
- Added corruption- and blood-moon-driven heartbeat and screen-edge atmosphere.
- Added common balance configuration and automated state checks.
- Tuned technique cooldowns, temporary Blood Puppet lifetime, and separated health,
  mana, and experience HUD bars.
